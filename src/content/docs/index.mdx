## Prueba el editor en tiempo real

Escribe abajo cualquier fórmula entre `$` o `$$` para ver cómo se renderiza en tiempo real, sin necesidad de iniciar sesión:

<MathPlayground />

Podés usar el [Panel de colaboradores](https://ergo-v2.tomycaruso.workers.dev/keystatic) para subir tus apuntes en formato `.mdx` y que se vean reflejados automáticamente en este sitio.
